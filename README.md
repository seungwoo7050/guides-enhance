# 알고리즘 설계와 검증

이 저장소는 핵심 자료구조와 알고리즘을 학습하고, 직접 구현한 결과를 독립적인 기준 계산으로 검증하기 위한 학습 기록입니다.

## 학습 목적

특정 문제의 풀이를 외우기보다 입력 조건을 분석하고 적절한 알고리즘을 선택하는 연습을 합니다. 알고리즘의 정확성과 시간·공간 비용을 설명하는 것을 중요하게 다룹니다.

## 기본 접근법

1. 입력·출력과 예외 조건을 정합니다.
2. 입력 크기에서 허용되는 시간·공간 비용을 계산합니다.
3. 필요한 상태와 자료구조를 고릅니다.
4. 정확성 근거를 적고 구현합니다.
5. 작은 입력의 직접 계산과 경계 입력으로 결과를 검증합니다.

문서는 특정 언어의 문법보다 문제 해결 원리와 검증 방법을 중심으로 정리합니다.
