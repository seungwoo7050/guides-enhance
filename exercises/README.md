# 실습 프로젝트

이 디렉터리에는 완성된 독립 프로젝트만 둡니다. 각 프로젝트는 상위 `guides` 저장소의 스크립트나 설정에 의존하지 않으며, 프로젝트 디렉터리만 따로 복사해도 실행하고 검사할 수 있습니다.

| 프로젝트 | 결과물 | 실행 환경 |
|---|---|---|
| [`ledgerlab-policy`](ledgerlab-policy/README.md) | 합성 보고서와 작업자 객체의 접근 가능 여부를 판정하고, 허용 범위를 벗어난 거절 이벤트를 요청 단위로 묶는 Python 라이브러리 | Python 3.10+ |
