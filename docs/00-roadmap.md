# 학습 로드맵

## 목표

C와 POSIX 프로그래밍 가이드의 기본 개념을 실행 결과와 연결하고, 입력·출력과 상태 변화를 스스로 설명합니다.

## 선행 준비

터미널에서 파일과 디렉터리를 다루고, 짧은 코드를 읽으며 실행 결과를 관찰할 수 있어야 합니다. 필요한 언어 문법과 도구 사용법은 학습 중 확인합니다.

## 학습 방향

편집·컴파일·실행 → 값과 메모리 수명 → API 계약 → POSIX 자원과 동시성

한 번에 모든 내용을 읽기보다 한 개념을 익힌 뒤 작은 구현이나 실험으로 확인합니다. 막힌 부분은 관련 개념으로 돌아가고, 확인한 전제와 실패 사례를 기록합니다.
