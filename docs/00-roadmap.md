# 학습 로드맵

## 목표

낯선 문제에서 입력 조건과 비용을 분석하고, 구현의 정확성을 설명하며, 독립적인 계산으로 결과를 확인하는 습관을 기릅니다.

## 선행지식

- 하나 이상의 언어로 함수, 조건문, 반복문, 배열 또는 list를 작성할 수 있어야 합니다.
- 작은 입력에서 변수 값과 자료구조의 변화를 손으로 추적할 수 있어야 합니다.

언어 문법 입문은 이 학습의 범위에 포함하지 않습니다.

## 기본 학습 방향

문제의 입력·출력과 예외 조건을 먼저 정하고, 입력 크기로부터 목표 복잡도를 계산합니다. 필요한 연산과 상태를 선택한 다음 정확성 근거를 적으며 구현합니다.

개념을 읽기만 하지 않고 작은 문제에 직접 적용합니다. 구현 결과는 다른 계산 방법과 경계 입력으로 확인하고, 실패한 입력은 줄여서 다시 검사할 수 있게 남깁니다.
